# Changelog

## 1.0.0

Initial public release.

### Server

- Self-hosted tabletop library and browser readers for PDF, comics, images, text, and Markdown.
- Recursive physical library sources, uploads, covers, users, and visibility controls.
- Persistent OCR workflow for scanned books/comics.
- Incremental extracted-text/chunk/semantic-embedding Knowledgebase.
- Basic and Advanced AI Ask modes with citations and character-aware context.
- Portable System Packs (`.ttlsys`) and characters (`.ttlchar`).
- Guided character creation, calculated rules, limits, structured collections, custom references, temporary effects, play mode, and advancement workflows.
- Built-in Generic D20 System Pack derived from SRD 5.2.1.
- Windows Server Manager for visible start/stop/status control.

### Local AI Backend

- Independent llama.cpp Backend Manager for Windows and Linux.
- Hardware-aware CUDA/Vulkan/CPU recommendations and runtime validation.
- Curated/arbitrary GGUF models, model/runtime downloads, API key, LAN access, configurable port, and autostart.

# Shadowrun: Anarchy System Pack

Phase 2 implements the Core Rulebook character-creation workflow, live creation budgets, core Skills, starter Qualities, Shadow Amp base types, and a starter weapon catalog.

The pack remains deliberately data-driven. Shadow Amp effect automation and deeper catalog content are Phase 3.

## Creation behavior

- 14 Core Rulebook creation steps
- game-level Attribute/Skill/Amp/weapon/gear/contact budgets
- Human and Troll Skill adjustments
- armor 6/9/12 Skill adjustment, with Troll natural Armor kept separate from the wearable armor choice
- Awakened/Emerged mutual exclusion and 2-point Amp cost
- metatype Attribute bonus validation
- five rated Skill slots plus Knowledge/custom rows
- one starting Specialization
- two Positive / one Negative Quality counters
- six-Shadow-Amp ceiling
- live budget badges using TTL's generic calculated-usage limits

Custom Shadow Amps, Qualities, Weapons, Knowledge Skills, Gear, and Contacts remain possible because Anarchy explicitly encourages player-created content.

# Old Gods of Appalachia System Pack v1.0.0

Tabletop Librarian System Pack based on the supplied Old Gods of Appalachia core rulebook.

## v1 scope

- Full ongoing character-sheet structure for Cypher/Old Gods play.
- Guided first-tier creation with Type, Descriptor, Focus, Arc, stat allocation, Type abilities, skills, gear and cyphers.
- Complete published Type, Descriptor and Focus choice lists.
- Complete suggested skill list and sample Character Arc list.
- First-tier Type ability catalog with eligibility by Type.
- Automatic starting Pool values and numeric Descriptor/Focus Pool/Edge/Armor modifiers where expressible by TTL's current rule engine.
- Tier advancement action and fields for higher-tier abilities.

TTL currently cannot automatically inject nonnumeric skill/ability/equipment rows from a selected Descriptor or Focus. Those fixed benefits are therefore recorded in the Skills and Focus / Other Abilities sections during creation. This is a limitation of the present generic System Pack engine, not of the source rules. Stable field/entity IDs are used so later pack revisions can migrate existing characters.

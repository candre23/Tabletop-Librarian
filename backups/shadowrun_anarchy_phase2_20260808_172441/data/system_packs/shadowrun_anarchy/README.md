# Shadowrun: Anarchy System Pack

Phase 1 establishes the character data model and dense sheet layout only.
Character creation budgets, metatype mechanics, compendium-driven skills,
Shadow Amps, qualities, equipment, advancement, and source provenance are
reserved for later phases.

The sheet deliberately uses one logical tab and section spans rather than
fixed-position page geometry. Wide screens place related sections side by
side; narrower character containers collapse them vertically. This is the
layout model intended for TTL's future tri-pane player workspace.

Physical and Stun capacities are calculated from Strength and Willpower using
the core-rule formulas. The current TTL resource type cannot yet bind its
maximum directly to a calculated field, so Phase 1 displays the calculated
capacities separately while the resource maxima remain configurable data.
